# AutoPost Studio — Landing Page

Landing page statis berbahasa Indonesia untuk jasa setup Instagram Autopost.

## Preview lokal
Buka `index.html` di browser. Tidak diperlukan proses build.

## Konfigurasi WhatsApp
Buka bagian bawah `index.html`, temukan:
```js
const WHATSAPP_NUMBER = "";
```
Isi nomor WhatsApp dengan kode negara dan angka saja, tanpa tanda plus, spasi, atau strip. Contoh format Indonesia: `6281234567890`.

## Deploy
Repository ini bisa diimpor ke Vercel sebagai proyek statis. Tidak membutuhkan environment variable atau server backend.

## Catatan
- Nama AutoPost Studio dan uraian layanan adalah copy awal yang dapat disesuaikan.
- Paket sengaja menggunakan konsultasi/custom, bukan harga yang belum dikonfirmasi.
- Pastikan nomor kontak benar sebelum situs dipublikasikan.
- Publikasi Instagram bergantung pada jenis akun, izin, dan dukungan platform. Hindari menjanjikan keberhasilan 100%.
